# Тише — психологический кабинет

Авторский лендинг с непрерывным мини-мультфильмом на Three.js. Десять глав сопровождают весь сайт: от входа в кабинет до финальной записи и футера. Скролл управляет ходьбой, посадкой, разговором, дыхательной паузой, появлением ноутбука и часов, раскрытием кабинета в сад и прощанием героев. Геометрия кабинета и персонажей создана процедурно; внешние 3D-модели, видео и платные ассеты не нужны.

Первая версия до переработки сохранена отдельно: `artifacts/archives/tishe-v1-original-2026-09-29.zip`. В ZIP находятся исходники и готовая сборка `dist`, 35 файлов. SHA-256: `C855C85ED65505CEC1B0CB6456094EF05FEFAB288439A54F863A5D469DACFEAC`.

## Запуск

```sh
npm install
npm run dev
```

Локальный адрес: http://127.0.0.1:5173/

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`. Её можно разместить на любом статическом хостинге. Шрифты включены в сборку, внешних запросов к Google Fonts нет.

## Состав

- `index.html` — разделы, тексты и нативные модальные окна.
- `src/style.css` — адаптивная вёрстка, типографика и оформление.
- `src/main.js` — привязка всего сюжета к прокрутке страницы, плавное обновление через GSAP ticker, главы, формы, навигация, режим уменьшенного движения.
- `src/room.js` — Three.js, процедурная диорама, персонажи, движение и освещение.
- `docs/concept.md` — сценарий и исследованные референсы.

## Настройка перед реальным запуском

Анна, Москва и стоимость 4 000 ₽ — демонстрационные данные. Замените их реальными сведениями специалиста; добавьте его подход, подтверждённое образование, контакты и условия работы.

Форма по умолчанию демонстрационная. Она проверяет имя, email/телефон/Telegram и согласие, не отправляет и не сохраняет личные данные. Результат ясно сообщает, что отправки не было.

Для реальной отправки задайте `VITE_CONTACT_ENDPOINT` в `.env.local` и пересоберите сайт. Endpoint должен принимать POST JSON:

```json
{"name":"Имя","contact":"email@example.com","format":"online","message":"Необязательное сообщение","consent":true}
```

Успешный ответ — HTTP 2xx. Формат может быть `online`, `office`, `undecided`. Для стороннего домена настройте CORS. Проверяйте поля и согласие на сервере, добавьте ограничение частоты обращений и действительную политику обработки данных. Не помещайте серверные секреты в переменные `VITE_*`: они входят в публичную сборку.

## SEO и поисковые роботы

Страница содержит текст в HTML, метаданные Open Graph и разметку Schema.org типа WebSite. `robots.txt` разрешает обход поисковым и ИИ-роботам. Production-сборка использует адрес из `.env.production`, соответствующий домену в `CNAME`, и создаёт canonical, og:url и sitemap.xml. При смене домена обновите `VITE_SITE_URL` и `CNAME`, затем пересоберите сайт. Для другого окружения адрес можно переопределить через `.env.local`. Без адреса canonical и sitemap намеренно не создаются. Проверьте доступность sitemap и добавьте сайт в Google Search Console и Яндекс Вебмастер.

Данные специалиста, города и цен здесь демонстрационные. Для настоящего проекта замените их проверенными данными и только после этого добавляйте разметку специалиста или организации и реальный адрес. Специальной разметки, гарантирующей упоминание в ИИ-ответах, не существует. Растровых изображений на сайте нет: сцена создаётся в WebGL, а favicon — векторный SVG.

## Доступность и производительность

- Нативный скролл, без его перехвата; обратимая история длится до конца страницы.
- Системный `prefers-reduced-motion` и отдельная кнопка спокойного режима.
- Нативный `<dialog>` с Escape, удержанием фокуса и возвратом к кнопке.
- Все главы находятся в обычном потоке документа; доступны поиск по странице, Tab и якоря. На мобильном сцена закреплена над областью чтения. Якоря и фокус учитывают её высоту.
- Fallback при отсутствии WebGL, тексты доступны независимо от сцены.
- Three.js загружается отдельным чанком, DPR ограничен 1.6, один источник света с тенями, рендер до 40 FPS. При скрытой вкладке рендер приостанавливается.
- Спокойный режим сохраняет главу, положение страницы и все тексты, останавливая циклические движения и ограничивая перемещения камеры.
- В localStorage сохраняется только настройка анимации.
